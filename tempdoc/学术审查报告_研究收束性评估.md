### 1.3 核心发现（论文可直接报告）

**发现一（层级结构反映）**：子标签 K* > 父标签 K*
- QU 家族：QU(28) < QUO(36) < QUC(59)
- 频率顺序与 K* 反向（QU 最频繁但 K* 最小），排除"仅因样本量"的替代解释

**发现二（反射类标签的不稳定性）**：
- RES(unstable) / RE(stable but K*=66) / REC(stable, K*=56)
- 与"缺少 client context"假设一致：反射类标签需要更多 latent + 更不稳定

**发现三（标签紧凑度分布）**：
- 紧凑型（K*<40）：QU、QUO、AF → 问题类 + 明确情感标签
- 分布型（K*>55）：QUC、REC、RE、SU → 边界模糊标签 + 上下文依赖标签
- 不稳定型：GI、SU、RES → 小样本 or 概念扩散

### 2.2 Devil's Advocate 核心质疑与应对

**质疑**：K* 层级可能只是样本量差异，不是语义结构。

**应对（已有数据）**：样本量与 K* 反向相关：
- QU（1974例）→ K*=28（最小）
- QUC（768例）→ K*=59（最大）
- 频率越高的标签，K* 反而越小 → 支持语义精细化而非样本量效应

**必须在论文讨论节加入**："Sample size vs K*"的散点图/相关系数，作为反驳替代解释的关键证据。
