# 人工标签能否被 SAE Features 预测？

可以，把第一步做成一个 **“SAE feature → human label 的可解码性实验”**。但这里有一个很关键的概念边界：

> **人工标签能被 SAE features 预测 ≠ LLM 完全理解了人工标签。**  
> 更准确地说，它测的是：**人工标签所代表的概念边界，是否存在于 LLM 的内部表征中，并且是否能被 SAE features 简单、稳定地读出来。**

所以你要测的不是抽象的“理解”，而是：

> **label information is encoded in SAE feature space.**

中文可以表述为：

> **人工标签信息在 LLM 内部 SAE 特征空间中的可解码程度。**

---

# 1. 核心实验问题

你可以把第一步定义成：

> 给定一个带人工标签的数据集 $D = \{(x_i, y_i)\}$，将每个样本输入 LLM，抽取某层 activation，并通过 SAE 得到 sparse feature vector $z_i$。如果一个简单 probe 可以从 $z_i$ 预测人工标签 $y_i$，说明人工标签对应的概念信息在 LLM 内部表征中是可解码的。

形式化一点：

$$
x_i \rightarrow h_i^{(l)} \rightarrow z_i^{(l)} \rightarrow \hat{y}_i
$$

其中：

- $x_i$：输入样本
- $y_i$：人工标签
- $h_i^{(l)}$：第 $l$ 层 hidden activation
- $z_i^{(l)}$：SAE 编码后的 sparse features
- $\hat{y}_i$：probe 预测出来的标签

你的问题就是：

> $z_i^{(l)}$ 到底包含多少关于 $y_i$ 的信息？

---

# 2. 不要直接用复杂分类器，先用简单 probe

建议第一版用：

## 首选：Sparse Logistic Regression / Linear Probe

$$
P(y_i \mid z_i) = \text{softmax}(Wz_i + b)
$$

原因是：  
如果一个 **简单线性模型** 就能从 SAE features 预测人工标签，说明标签信息不是藏得很深，而是比较直接地存在于 feature space 里。

如果你一开始就用 MLP、XGBoost、随机森林，预测效果可能很好，但解释会变弱，因为你不知道是 SAE features 本身对齐，还是分类器学出了复杂边界。

推荐顺序：

1. **Majority baseline**
2. **Bag-of-words / TF-IDF baseline**
3. **Raw hidden state linear probe**
4. **SAE feature linear probe**
5. **SAE feature sparse probe**
6. 可选：**nonlinear probe**

重点比较的是：

> SAE features 是否比原始文本特征更能表达人工标签？  
> SAE features 是否比 raw activation 更可解释？  
> 线性 probe 是否足够好？

---

# 3. 你真正要报告的不是 accuracy，而是一组 alignment 指标

如果你的标签类别不均衡，尤其有 misc / other 类，accuracy 很容易骗人。建议至少报告这些：

---

## 3.1 Macro-F1

这是最重要的主指标。

$$
MacroF1 = \frac{1}{K}\sum_{k=1}^{K} F1_k
$$

它不会让大类压倒小类。  
如果你的 misc 类很大，macro-F1 比 accuracy 更合适。

---

## 3.2 Balanced Accuracy

$$
BalancedAcc = \frac{1}{K}\sum_{k=1}^{K} Recall_k
$$

它回答的是：

> 每个标签平均来看，模型能不能识别出来？

---

## 3.3 Per-label F1

这对你的研究特别重要，因为你关心的是：

> 哪些人工标签和 LLM 内部表征对齐？  
> 哪些不对齐？

例如你可能会发现：

| Label | F1 | 解释 |
|---|---:|---|
| code | 0.91 | 高度可解码，LLM 内部有清晰代码特征 |
| math | 0.84 | 比较可解码 |
| emotion | 0.68 | 中等对齐 |
| misc | 0.31 | 人工 misc 标签和内部表征弱对齐 |

这个表会比整体 accuracy 有用得多。

---

## 3.4 Confusion Matrix

你需要看人工标签之间在 SAE space 里如何被混淆。

比如：

| Human label | 常被 probe 预测成 |
|---|---|
| misc | coding / reasoning / safety |
| ambiguous | misc / clarification |
| safety | refusal / harmful |
| factual | reasoning |

这一步可以直接揭示：

> 人工标签边界和 LLM 内部 feature 边界在哪里冲突。

尤其是 misc。如果很多 misc 样本被稳定预测成更具体的类别，这说明：

> 人工 misc 可能是粗标签，但 LLM 内部并不把它们当作同一种东西。

---

# 4. 建议定义一个 “Label–Feature Alignment Score”

你可以构造一个比较干净的指标，不只是报告 F1。

我建议定义：

$$
A_l(y) = \frac{F1_l(y) - F1_{\text{baseline}}(y)}{1 - F1_{\text{baseline}}(y)}
$$

其中：

- $A_l(y)$：第 $l$ 层上，标签 $y$ 的对齐分数
- $F1_l(y)$：用第 $l$ 层 SAE features 预测标签 $y$ 的 F1
- $F1_{\text{baseline}}(y)$：baseline 的 F1，比如 majority baseline 或 TF-IDF baseline

这个分数范围大致可以理解为：

| Alignment Score | 含义 |
|---:|---|
| 接近 1 | 标签几乎可以被 SAE features 完整读出 |
| 接近 0 | SAE features 不比 baseline 好 |
| 小于 0 | SAE features 比 baseline 还差，可能无对齐或表征冲突 |

这样你就可以画一个：

> **layer × label 的 alignment heatmap**

比如：

| Label | Layer 8 | Layer 16 | Layer 24 |
|---|---:|---:|---:|
| code | 0.62 | 0.81 | 0.77 |
| safety | 0.22 | 0.65 | 0.84 |
| misc | 0.05 | 0.18 | 0.12 |
| emotion | 0.31 | 0.52 | 0.49 |

这个图会非常有论文感。

---

# 5. 对齐程度最好分成三个层级

你可以把 “LLM 与人工标签理解是否对齐” 分成三种证据强度。

---

## Level 1：Decodability Alignment

问题：

> 人工标签能否从 SAE features 中预测出来？

指标：

- Macro-F1
- Per-label F1
- Balanced accuracy
- AUROC
- Probe cross-entropy

结论类型：

> 标签信息存在于 LLM 内部 SAE feature space 中。

这是你现在要做的第一步。

---

## Level 2：Structural Alignment

问题：

> 人工标签的类别边界，是否和 SAE feature space 中的聚类结构一致？

指标：

- intra-label similarity
- inter-label similarity
- silhouette score
- adjusted Rand index
- normalized mutual information

例如：

$$
IntraSim(y) > InterSim(y, y')
$$

如果同一人工标签内部的 SAE pattern 很相似，不同标签之间差异明显，说明结构对齐。

但如果：

- 同一标签内部很分散
- 不同标签之间反而很近
- misc 内部分成多个稳定子簇

那说明人工标签和模型内部概念边界不一致。

---

## Level 3：Semantic / Causal Alignment

问题：

> 预测标签的 SAE features 语义上真的对应人工标签吗？它们是否影响模型行为？

需要做：

- top activating examples
- feature interpretation
- feature ablation
- feature steering
- label prediction change

比如某个 feature 很能预测 “safety” 标签，但 top examples 发现它其实只是在捕捉 “kill / bomb / drug” 这类表面词，那它就是 spurious alignment。

所以第一步的 probe 只能证明：

> SAE features encode label-predictive information.

不能直接证明：

> LLM conceptual understanding is aligned with humans.

这个区别一定要写清楚。

---

# 6. 推荐实验流程

你可以按这个 pipeline 做。

---

## Step 1：准备数据

数据格式：

| id | text | human_label |
|---|---|---|
| 001 | ... | code |
| 002 | ... | misc |
| 003 | ... | safety |
| 004 | ... | factual |

注意：

- 每个 label 尽量样本数相近
- 如果 misc 太大，可以保留原始比例，同时额外做 balanced subset
- 如果有多个 annotator，最好保留 label agreement score

---

## Step 2：固定 prompt

你要区分两个设置。

### Setting A：自然理解 setting

```text
{text}
```

只输入文本，不告诉模型要分类。

这测的是：

> 模型自然阅读时，内部是否形成了和人工标签相关的表征。

### Setting B：任务诱导 setting

```text
Classify the following text according to the annotation schema.

Text:
{text}

Label:
```

这测的是：

> 当模型知道自己要做分类任务时，是否形成了和人工标签更一致的表征。

这两个 setting 都值得做。  
如果 B 明显高于 A，说明人工标签信息不是自然浮现的，而是被任务 prompt 激活出来的。

---

## Step 3：抽取 activation

对每个样本，记录：

$$
h_i^{(l,p)}
$$

其中：

- $l$：layer
- $p$：token position

推荐先用：

- last input token
- final token before answer
- mean pooling over input tokens

第一版可以先做：

> layer = middle / late layers  
> position = last input token

不要一开始把 token position 搞太复杂。

---

## Step 4：SAE encoding

把 activation 输入 SAE：

$$
z_i^{(l)} = SAE_{\text{enc}}(h_i^{(l)})
$$

对 $z_i$ 可以有三种表示：

1. **Raw SAE activation**  
   保留 feature activation value。

2. **Binary SAE activation**  
   只记录 feature 是否被激活。

3. **Top-k SAE activation**  
   每个样本只保留激活最高的 k 个 features。

我建议三种都试一下。  
如果 binary features 也能预测标签，说明某些 feature 的出现本身就有标签信息。

---

## Step 5：训练 probe

用 stratified split：

- train：70%
- dev：10%
- test：20%

或者 5-fold cross validation。

probe 建议：

```text
Input: SAE feature vector z_i
Output: human label y_i
Model: L1 / ElasticNet Logistic Regression
```

为什么用 L1 或 ElasticNet？

因为它会自动选出少数重要 features，方便你解释：

> 哪些 SAE features 最支持某个人工标签？

---

# 7. Baseline 非常重要

你至少需要这些 baseline，不然很难说 “SAE features 真的有意义”。

---

## Baseline 1：Majority Class

永远预测最多的标签。

这是最低线。

---

## Baseline 2：Random Labels

把 $y_i$ 随机打乱，再训练 probe。

如果随机标签也能预测得不错，说明你的实验有泄漏或数据太小。

---

## Baseline 3：TF-IDF / Bag-of-words

这是非常重要的文本表面特征 baseline。

如果 SAE probe 只和 TF-IDF 差不多，说明 SAE 可能只是捕捉了表面词汇。

如果 SAE probe 显著超过 TF-IDF，说明它可能编码了更抽象的概念结构。

---

## Baseline 4：Raw Hidden State Probe

用原始 activation $h_i$ 直接预测标签。

对比：

| Representation | 预测强度 | 可解释性 |
|---|---:|---:|
| TF-IDF | 文本表面线索 | 中等 |
| raw activation | 内部信息多 | 低 |
| SAE features | 内部信息 + 可解释性 | 高 |

你的理想结果是：

> SAE features 接近 raw activation 的预测能力，但可解释性更强。

---

# 8. 你可以这样解释不同结果

---

## 情况 1：SAE Probe 表现很高

例如 macro-F1 = 0.82。

说明：

> 人工标签所对应的概念信息在 LLM 的 SAE feature space 中高度可解码。

但还不能马上说“完全对齐”。下一步要看 feature 语义是否合理。

---

## 情况 2：整体表现高，但 misc 表现低

这是很可能、也很有价值的结果。

说明：

> 大多数人工标签和 LLM 内部表征较一致，但 misc 标签可能不是一个统一概念，而是多个内部概念的混合。

这正好支持你的研究主线。

---

## 情况 3：misc 很容易被预测出来

这反而要小心。

可能说明 misc 有很强的表面特征，例如：

- 特定模板
- 标注偏差
- 数据来源偏差
- 长度分布特殊
- 包含某些高频词

这时要做控制实验：

- 控制文本长度
- 控制来源
- 去掉明显关键词
- 用 TF-IDF baseline 对比
- 检查 top SAE features

---

## 情况 4：SAE Probe 不如 Raw Activation

这很正常。

说明 SAE 可能丢失了一些 label-relevant information，或者已有 SAE 不适合你的任务域。

你可以报告：

> SAE improves interpretability at the cost of some predictive information.

这不是失败，而是一个 trade-off。

---

# 9. 最关键的分析产物

你第一步最好产出 5 个结果。

---

## 结果 1：整体预测结果表

| Representation | Accuracy | Macro-F1 | Balanced Acc |
|---|---:|---:|---:|
| Majority | 0.42 | 0.10 | 0.20 |
| TF-IDF | 0.61 | 0.48 | 0.50 |
| Raw activation | 0.78 | 0.71 | 0.73 |
| SAE features | 0.74 | 0.68 | 0.70 |
| SAE binary features | 0.69 | 0.62 | 0.64 |

---

## 结果 2：Per-label F1

| Label | F1 | Alignment interpretation |
|---|---:|---|
| code | 0.91 | strongly aligned |
| math | 0.84 | strongly aligned |
| safety | 0.79 | aligned |
| emotion | 0.62 | partially aligned |
| misc | 0.28 | weakly aligned |

---

## 结果 3：Layer-wise Alignment Heatmap

横轴 layer，纵轴 label，颜色是 $A_l(y)$。

你要找：

- 哪些 label 在 early layer 就可解码？
- 哪些 label 到 late layer 才出现？
- misc 是否始终低？
- 是否存在某个 layer 最对齐人工标签？

---

## 结果 4：Confusion Matrix

尤其看 misc 被预测成什么。

如果 misc 被预测成多个具体类别，你就可以说：

> SAE features suggest that human misc labels collapse internally separable model concepts.

---

## 结果 5：Top Features for Each Label

对每个 label，找 probe 权重最高的 SAE features：

$$
TopFeatures(y) = \arg\max_j W_{y,j}
$$

然后列出：

| Label | SAE feature | Weight | Top activating examples | Tentative interpretation |
|---|---:|---:|---|---|
| code | f_1023 | 2.31 | examples with Python syntax | code syntax |
| safety | f_884 | 1.97 | harmful request examples | unsafe intent |
| misc | f_441 | 0.62 | mixed examples | unclear / heterogeneous |

这里很重要：  
如果 misc 的 top features 很杂、语义不稳定，就说明 misc 与 LLM 内部概念结构弱对齐。

---

# 10. 你可以提出一个严谨的测量定义

你可以在 proposal 里这样写：

> We measure human–LLM conceptual alignment as the degree to which human annotation labels are linearly decodable from SAE-derived internal features of the LLM. High decodability indicates that label-relevant information is explicitly represented in the model’s sparse feature space, while low decodability suggests weak alignment or heterogeneous internal representations. We further compare SAE-based probes against lexical, majority-class, randomized-label, and raw-activation baselines to distinguish genuine representational alignment from superficial dataset artifacts.

中文版本：

> 本研究将人工标签与 LLM 内部概念理解的对齐程度，操作化定义为：人工标签能否被 LLM 内部 SAE 特征以简单、稳定、可解释的方式预测出来。若某一标签可以被 SAE features 高准确率、低复杂度地线性解码，说明该标签所对应的概念信息在模型内部表征中较为显式；若某一标签难以被预测，或其预测依赖杂乱、不可解释的 features，则说明人工标签与模型内部概念边界可能存在不对齐。

---

# 11. 我建议你第一步的最终设计

最小但严谨的版本可以是：

1. 对每个样本抽取 LLM 某几层 activation。
2. 用 SAE 得到 sparse feature vector。
3. 用 L1 logistic regression 从 SAE features 预测人工标签。
4. 报告 macro-F1、balanced accuracy、per-label F1。
5. 和 majority、random-label、TF-IDF、raw activation baseline 比较。
6. 构建 layer × label 的 alignment heatmap。
7. 检查 misc 的 confusion pattern 和 top predictive features。

这一步能回答：

> 人工标签所编码的概念边界，是否在 LLM 的 SAE feature space 中可被读出？

而你的下一步就自然变成：

> 如果某些标签，尤其 misc，不能被稳定预测，那么它们在 SAE feature space 中到底被模型拆成了什么内部子结构？
