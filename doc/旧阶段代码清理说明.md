# 旧阶段代码清理说明

更新时间：2026-05-20

## 清理目标

本次清理的目标是让仓库代码结构和当前研究主线保持一致。当前主线已经从早期的 `RE/NonRE` 小样本与 cactus 中间数据，转向全量 MISC 行为单元：

```text
data/mi_quality_counseling_misc/misc_annotations/*/*.jsonl
```

当前核心流程是：

```text
MISC unit_text
-> Llama-3.1-8B hidden states
-> OpenMOSS / lm-saes SAE latent features
-> latent x MISC label matrix
-> Mapping Structure / 后续可解释性 / 因果候选组
```

因此，早期只服务于 cactus 数据构建、基础文本生成 demo、Stage2 activation extraction 旧实验阶段的代码不再作为当前主线维护。

## 已删除的旧代码与旧数据残留

### cactus 旧数据构建与验证

删除：

- `build_cactus_dataset.py`
- `verify_cactus_pipeline.py`
- `data/cactus/README.md`
- `data/cactus/cactus_re_small_1500.jsonl`
- `data/cactus/cactus_re_small_1500_preview.csv`
- `data/cactus/cactus_re_small_1500_stats.json`

原因：

- 当前主实验不再从 cactus 构造 RE/NonRE 小数据集。
- 云端因果脚本已经默认拒绝 `data/cactus` 等旧数据路径，避免误跑旧口径。
- 保留这些文件容易让后续运行流程回到过时的数据入口。

### Stage2 activation extraction 旧阶段

删除：

- `run_stage2_activation_extraction.py`
- `src/nlp_re_base/stage2_activation_extraction.py`
- `test_stage2_smoke.py`

原因：

- 当前主流程已经在 `run_sae_evaluation.py` 中统一完成 hidden states 抽取、SAE feature 聚合、结构指标、功能指标和特征保存。
- 新的矩阵与解释性分析直接使用 `feature_store/utterance_features.pt`、`feature_store/utterance_activations.pt` 和 `functional/misc_label_mapping/`。
- 旧 Stage2 单独抽层、单独训练 probe 的流程会和当前全量 MISC 口径重复。

### 基础推理 demo 与临时检查入口

删除：

- `run_inference.py`
- `src/nlp_re_base/infer.py`
- `inspect_dataset.py`

原因：

- `run_inference.py` 只是早期文本生成 demo，不参与 SAE 结构指标、功能指标、MISC 矩阵或解释性分析。
- `inspect_dataset.py` 是临时数据查看入口，已被 `src/nlp_re_base/data.py`、`test_dataset_loader_smoke.py` 和正式报告替代。
